# Jėga

A personal workout **routine planner** (PWA). Create routines, organize them in
folders, build each exercise's set and rep scheme, and see a muscle-volume
heat-map — all stored on your device and usable offline.

Open the Pages URL in Safari on iPhone and choose **Add to Home Screen** to
install it as an app.

Exercise catalog, images and how-to content are for personal use.
